# Unified physics kill experiments

This folder is an archive of throwaway experiments and is not part of the product. It lives only on the archive branch `claude/project-thread-mqnuze` (draft pull request #49), which is kept for reference and is never merged into main. The only way any of this code reaches main is the TypeScript port of `reference-model/` into `packages/sim-hull`.

These scripts are throwaway kill experiments, not the simulator. Each one tried to break one idea from the unified hull and sail proposal, and the GIFs they draw show how the idea held up. The hull direction that survived is recorded in `docs/adr/0014` on main; `reference-model/` is the JavaScript model it rests on, and the starting point of the port. Nothing in `packages/` imports them. The results, tables and verdicts are in `docs/research/unified-experiments/`.

## Prerequisites

You need Node 22, Python 3 with numpy and Pillow (openpyxl too for the experiments that read the Delft tank data), ffmpeg, and the DejaVu fonts at `/usr/share/fonts/truetype/dejavu/`. The canvas experiments (s1-vortex-2d, s1b-leech, s4-sail-3d) also need Playwright with Chromium, which you install once in this folder:

```sh
cd experiments/unified-physics
npm install --no-save playwright
npx playwright install chromium
```

Every script writes into a git-ignored `out/` folder beside itself and can be run from any folder. Downloaded tank data goes into a git-ignored `dl/` folder beside the scripts. Chromium always runs headless.

## External data

The hull experiments h1b-holdout, h3-waves and h3b-waves-fix compare against the open Delft Systematic Yacht Hull Series. The data is not in the repository. Download it into `dl/` from the 4TU.ResearchData records the scripts name: measurements at https://doi.org/10.4121/21501402, hydrostatics at https://doi.org/10.4121/21501375 and hull geometry (IGES) at https://doi.org/10.4121/21501330.

The `snatch_in_sail.py` cases above are read back from the labels in `gifC.py`. They reproduce the numbers in the result (15 snatches for the lumped air mass, none for the other two), but the GIF can differ slightly from the published one.
