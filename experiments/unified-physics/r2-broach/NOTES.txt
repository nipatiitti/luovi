r2-broach: heel, helm balance and the broach on the sailing-test model.
Result: docs/research/unified-experiments/r2-broach.md

Prerequisites: Node 22, ffmpeg, Playwright with Chromium (installed once in experiments/unified-physics, see README.md).
Every script reads and writes out/ beside itself (git-ignored) and can be run from any folder. Nothing is downloaded.

Files
  model.js          the r2 model (every change is marked "r2"; switches in C.heel turn each term off)
  model_old.js      the sailing-test model with read-outs added only (no physics change)
  model-r2.diff     unified diff of model.js against the sailing-test model.js (that model is not in the repo; model_old.js is it plus read-outs)
  r2lib.mjs         loads both models side by side; lib.mjs takes MODEL from the environment
  gen_hulls.mjs gen_sails.mjs   the sailing-test boat and sail tables -> out/hulls.json, out/sails.json (regenerated byte for byte)
  gen_hulls_kf.mjs boats_kf.mjs the keel-forward variant -> out/hulls_kf.json
  draw_r2.js render_r2.mjs      the GIF renderer; draw.js render.mjs scen_all.mjs scen_rudder.mjs page.html build_page.mjs
                                test_page.mjs check_orc.mjs are the sailing-test originals, unchanged

Regenerate, from this folder:
  mkdir -p out
  node gen_hulls.mjs                 # 20 s
  node gen_sails.mjs                 # 5 s
  node gen_hulls_kf.mjs              # 20 s, only for sens.mjs

The numbers in the result:
  node diag.mjs                      # steady helm and turning-moment budget against wind, after
  MODEL=./model_old.js node diag.mjs # the same, before (BOATS=hboat,ifboat picks boats)
  node budget.mjs                    # captive budget at fixed heel, 6.5 kn, 4 deg leeway (BOAT=ifboat for the Folkboat)
  node explore.mjs                   # puffs, tiller free, bearing away, before and after (SET=2 for the harder cases; BOAT=ifboat)
  node upright.mjs                   # side-effect check on the upright rudder
  node sens.mjs                      # keel 0.40 m forward, and the Folkboat (needs out/hulls_kf.json)
  node scen_r2.mjs                   # the three GIF scenarios and their numbers -> out/numbers-r2.json, 10 s

The GIFs (after scen_r2.mjs):
  node render_r2.mjs g1-puff-broach
  node render_r2.mjs g2-bear-away-pinned
  node render_r2.mjs g3-ease-main
